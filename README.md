# Abhishek Singh — Creative Portfolio & Motion Design

An immersive, motion-rich digital portfolio featuring high-performance canvas scroll frame animation, bespoke typography, and a dark obsidian & crimson aesthetic.

## Features

- **240-Frame Interactive Scroll Animation**: Smooth lerp-damped background animation engine rendering on HTML5 canvas.
- **Graphic Design Showcase**: Curated selection of brand identities, posters, editorial typography, and UI/UX projects with a Gaussian-blur full-view lightbox modal.
- **Video Projects Suite**: High-impact video projects linked directly to YouTube podcast edits, Instagram reels, and YouTube shorts.
- **Responsive Architecture**: Fluid layout optimized across mobile, tablet, and ultra-wide desktop viewports.
- **Interactive Lightbox**: Full-resolution uncropped visual modals with keyboard accessibility (`Esc` to close).

## Tech Stack

- **Core**: Vanilla HTML5, CSS3, JavaScript (ES6+)
- **Canvas Engine**: HTML5 Canvas with custom LERP damping (`0.085`) and Retina / High-DPI support
- **Typography**: Plus Jakarta Sans, Bebas Neue, Caveat
- **Design System**: Dark obsidian glassmorphism with crimson accents (`#e52b38`)
